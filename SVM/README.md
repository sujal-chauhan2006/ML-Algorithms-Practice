
# Support Vector Machine (SVM) Classification

## 📌 Project Overview

This notebook demonstrates the implementation of the **Support Vector Machine (SVM)** algorithm for a classification problem using **Scikit-learn**. It covers the complete machine learning workflow, from data preprocessing to model evaluation and decision boundary visualization.

---

## 🎯 Objectives

- Understand the working principle of Support Vector Machines.
- Learn why feature scaling is important for SVM.
- Train an SVM classifier using Scikit-learn.
- Visualize the decision boundary.
- Evaluate the model using classification metrics.
