
# 🤖 Logistic Regression Practice

## 📌 Overview

This repository contains my hands-on practice and implementation of concepts related to Logistic Regression and Classification in Machine Learning.

The goal of this repository is to understand the mathematical intuition behind classification algorithms, decision boundaries, probability-based predictions, and optimization techniques through both theory and practical implementation.

Each notebook focuses on a specific concept that builds the foundation of Logistic Regression.
