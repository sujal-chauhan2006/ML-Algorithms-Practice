
# 🌳 Core Bagging (Bootstrap Aggregating)

This project demonstrates the core concept of **Bagging (Bootstrap Aggregating)** using multiple Decision Tree classifiers.

Instead of using Scikit-Learn's `BaggingClassifier`, the notebook manually creates bootstrap samples, trains multiple Decision Trees, and compares their predictions.

---

## 📌 Project Overview

Bagging is an Ensemble Learning technique that improves prediction performance by combining predictions from multiple models trained on different bootstrap samples.

This notebook covers:

- Data preprocessing
- Label Encoding
- Bootstrap Sampling
- Training Multiple Decision Trees
- Decision Boundary Visualization
- Individual Model Predictions
- Ensemble Learning Concept

---

## 📂 Dataset

- Features Used:

  - Petal Length
