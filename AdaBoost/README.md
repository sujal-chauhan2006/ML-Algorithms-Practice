
# AdaBoost from Scratch

## 📌 About
This notebook demonstrates the implementation of the AdaBoost (Adaptive Boosting) algorithm from scratch using Python. It explains how AdaBoost trains multiple weak learners (Decision Stumps), updates sample weights after each iteration, calculates alpha (model weight), performs weighted sampling, and combines all weak learners to make the final prediction. The notebook also includes decision boundary visualizations for better understanding.
